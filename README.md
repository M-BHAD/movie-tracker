# 🎬 Movie Tracker

A simple Python-based Movie Tracker that helps users manage their movie watchlist and keep track of movies they have already watched.

## ✨ Features

- Add movies to your watchlist.
- View movies you plan to watch.
- Mark movies as watched.
- Remove movies from your lists.
- Interactive menu-driven interface.

## 🛠️ Technologies Used

- Python
- Lists
- Functions
- Loops
- Conditional Statements

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```
